# Native UI

- Use only stable, documented WinUI 3 and Windows APIs.
- Prefer latest stable controls and patterns; avoid unnecessary third-party UI libraries.
- Keep the result polished: correct states, keyboard/focus, DPI awareness, theme support (light/dark), accessibility (Narrator), and consistency with the existing compact layout.
- Respect existing UI contracts and layout checks.
- Note what requires physical visual validation on Windows.
